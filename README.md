# Student-management-system
This is my first project using Python and SQLite.  I built a Student Management System where you can  add, view, search, update and delete student records.  I learned Python from basics and connected it with  a database for the first time. Still learning and  improving every day!
## Features
- Add new student
- View all students
- Search student by roll number
- Update student details
- Delete student

## Technologies Used
- Python 3
- SQLite3

## How to Run
1. Install Python
2. Run student_management.py
3. Use the menu to manage students
